# Mohammed Saif Ullah Khan | Portfolio

Personal portfolio site built with plain HTML, CSS and JavaScript.

## About me

Hi! I'm Saif, a Computer Science Engineer passionate about cloud technologies and clean code. I enjoy building scalable web applications and continuously learning new tools and frameworks.

## What's on the site

- About, experience and education sections
- Project showcase linking to my GitHub repositories:
  - [Cloud computing internship](https://github.com/Saifk26/cloud-computing-project)
  - [Jobinator](https://github.com/Saifk26/Jobinator)
  - [Certifications](https://github.com/Saifk26/certifications)
- Contact section with email and LinkedIn links
- Responsive layout with a hamburger menu on small screens

## Files

| File | Purpose |
| --- | --- |
| `index.html` | The single-page site |
| `style.css` | Main styles |
| `mediaqueries.css` | Responsive breakpoints |
| `script.js` | Mobile menu toggle |
| `assets/` | Images, icons and resume |

## Run locally

Clone the repository and open `index.html` in a browser. No build step is needed.
